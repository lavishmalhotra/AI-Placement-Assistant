# AI Placement Preparation Assistant

An AI-powered desktop assistant developed using Python, Tkinter, and OpenRouter API.

This chatbot helps students with:
- Placement preparation
- Coding guidance
- DSA roadmap
- Resume tips
- AI and technology queries
- Interview preparation

---

# Features

- Real-time AI chatbot
- Voice input support
- Smart conversational responses
- Chat memory
- Export chat option
- Typing animation
- Modern dark-themed GUI
- Multithreading support

---

# Technologies Used

- Python
- Tkinter
- OpenRouter API
- OpenAI SDK
- SpeechRecognition
- pyttsx3

---

# Installation

Clone the repository:

```bash
git clone https://github.com/lavishmalhotra/AI-Placement-Assistant.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the project:

```bash
python chatbot.py
```
